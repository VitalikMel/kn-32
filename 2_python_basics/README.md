#### try / except / finally

```python
try:
    result = 10 / 0
except ZeroDivisionError as error:
    print("Перехоплена помилка:", error)
finally:
    print("Блок finally завжди виконується.")
```

Результат програми:

```text
Перехоплена помилка: division by zero
Блок finally завжди виконується.
Квадрати чисел: [1, 4, 9, 16]
```

#### Лямбда-функція

Лямбда-функція — це короткий запис функції без обов’язкового визначення через `def`. У прикладі lambda підносить число до квадрата, а `map` застосовує її до кожного елемента списку.

```python
square = lambda value: value ** 2
numbers = [1, 2, 3, 4]
squared_numbers = list(map(square, numbers))
print("Квадрати чисел:", squared_numbers)
```
