# Звіт до роботи

## Тема: Оформлення та здача робіт

### Мета роботи

Налаштувати середовище роботи у VS Code, створити публічний репозиторій GitHub, налаштувати інтеграцію з ним, написати першу програму на Python та оформити звіт у форматі Markdown.

---

### Виконання роботи

1. У Visual Studio Code встановлено та перевірено розширення **Python** і **Jupyter**. Для Copilot використано вбудоване розширення GitHub Copilot Chat.
2. Створено папку `1_python_program` з програмами, ноутбуком і звітом.
3. Створено програму [my_first_app.py](./my_first_app.py). У ній змінено ім’я на `Віталій`, а місто — на `Львів`.
4. Програму запущено через інтерпретатор Python.
5. Створено Jupyter Notebook [my_first_app.ipynb](./my_first_app.ipynb), у який додано Markdown-заголовок, програмний код і опис роботи.
6. Створено AI-програму [ai_suggested_program.py](./ai_suggested_program.py): попросивши Copilot запропонувати просту першу програму, отримано ідею конвертера температур із поясненням формули. Програму перевірено запуском у Python.

#### Результат запуску `my_first_app.py`

```text
Віталій start programming at 2026-10-30 14:39:02.467738. Львів is the best city!
```

#### Результат запуску програми, запропонованої AI

```text
20 C = 68.0 F
```

#### Код першої програми

```python
from datetime import datetime

name = "Віталій"
location = "Львів"

print(f"{name} start programming at {datetime.now()}. {location} is the best city!")
```

#### Програма від AI/Copilot

```python
def celsius_to_fahrenheit(celsius: float) -> float:
    return celsius * 9 / 5 + 32


temperature = 20
print(f"{temperature} C = {celsius_to_fahrenheit(temperature):.1f} F")
```

Програма пояснює перетворення градусів Цельсія у градуси Фаренгейта за формулою `F = C * 9 / 5 + 32`.
