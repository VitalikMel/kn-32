# Відпрацювання 17 листопада

## Тема

Теорія про класи та конструктор.

## Теоретична частина

**Клас** — це шаблон або опис для створення об'єктів.

**Конструктор** — це метод `__init__()`, який автоматично викликається під час створення об'єкта. Він ініціалізує атрибути об'єкта.

- `class` оголошує клас.
- `__init__` є конструктором.
- `self` посилається на конкретний об'єкт, що створюється.
- атрибутами можуть бути дані, наприклад `name` або `age`.

## Практична частина

Створено простий клас [student.py](./student.py):

```python
class Student:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def introduce(self):
        return f"Мене звати {self.name}, мені {self.age} років."


student = Student("Віталій", 17)
print(student.introduce())
```

## Результат виконання

```text
Мене звати Віталій, мені 17 років.
```
