# Звіт до роботи

## Тема: Знайомство з ООП

### Мета роботи

Навчитися використовувати основні принципи ООП, розглянути конструювання класу та створення об'єктів, а також виконати індивідуальні завдання для модифікації класу.

---

### Виконання роботи

1. Створено скрипт [my_name.py](./my_name.py) із класом `MyName`.
2. Створено Notebook [my_name.ipynb](./my_name.ipynb) із прикладами лекції та перевіркою індивідуальних завдань.
3. Додано ім’я `Vitaliy` до списку імен.
4. Реалізовано атрибути екземпляра, класову змінну, властивості, класовий і статичний методи.
5. Реалізовано перевірку імені, капіталізацію першої літери, підрахунок довжини імені та налаштовуваний email-домен.
6. Додано властивість `full_name` та метод `save_to_file`.

#### Клас і створення об'єктів

```python
class MyName:
    total_names = 0

    def __init__(self, name=None, domain="itcollege.lviv.ua"):
        if name is None:
            name = "Anonymous"
        elif not name.isalpha():
            raise ValueError("Ім'я може містити лише літери!")

        self.name = name[0].upper() + name[1:]
        self.domain = domain
        MyName.total_names += 1
        self.my_id = MyName.total_names
```

#### Відповіді на запитання

1. **Чому при `None` створюється `Anonymous`?** У конструктора перевіряється `name is None`, після чого змінній присвоюється значення `"Anonymous"`.
2. **Як змінити текст привітання?** Передати текст як аргумент методу `say_hello("Welcome!")`.
3. **Підрахунок букв імені.** Реалізовано властивість `name_length`, яка повертає `len(self.name)`.
4. **Різниця кількості імен у списку й створених об'єктів.** У реалізованій роботі в словнику `all_names` створюється рівно один об'єкт для кожного елемента кортежу, тому для чотирьох елементів буде `4` об'єкти. У початковому прикладі реалізація через `anonymous_user()` всередині конструктора могла створити додатковий об'єкт і збільшити кількість лічильника.
5. **Велика перша літера.** У конструктора використано `name[0].upper() + name[1:]`.
6. **Домен email.** Метод `create_email(domain=None)` дозволяє передати новий домен або використовує домен екземпляра.
7. **Перевірка імені.** Використано `ValueError("Ім'я може містити лише літери!")`, якщо рядок містить цифри чи символи або не є рядком.
8. **Властивість `full_name`.** Повертає формат `User #<id>: <name> (<email>)`.
9. **Збереження у файл.** Метод `save_to_file(filename="users.txt")` відкриває файл у режимі додавання `a` та записує рядок у форматі `full_name`.
