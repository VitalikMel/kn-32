# Навчальний репозиторій «Кн-32»

## Про проєкт

Цей репозиторій призначений для лабораторних і практичних робіт з інформаційних технологій. Тут будуть зберігатися навчальні матеріали, приклади коду, звіти та інші файли, створені під час навчання.

## Робота з репозиторієм у VS Code

1. Встановіть Git та Visual Studio Code.
2. Клонуйте репозиторій через кнопку **Clone Git Repository...**.
3. Відкрийте локальну папку проєкту у VS Code.
4. Увімкніть автозбереження: **File → Auto Save**.
5. Вносите зміни в файли та зберігайте їх.
6. На панелі **Source Control** додайте змінені файли до staged changes за допомогою кнопки `+`.
7. Введіть коротке повідомлення коміту та натисніть **Commit**.
8. Натисніть **Sync Changes**, щоб надіслати коміт на GitHub.

## Майбутні роботи

1. Ознайомлення з Git та GitHub.
2. Створення та форматування Markdown-документів.
3. Використання гілок у Git.
4. Спільна робота над проєктами.
5. Виконання лабораторних і практичних завдань.
6. Підготовка звітів у Markdown.
7. Фінальне оформлення навчального портфоліо.
